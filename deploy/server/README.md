# Debian 13 · drop.pollybich.ru

Нужны Docker Engine, свободные TCP-порты 80/443 и DNS-запись `drop.pollybich.ru`, направленная на ваш сервер. Установку выполняет владелец сервера. SSH-пароли и ключи передавать не нужно.

## Новая установка

```bash
apt-get update && apt-get install -y git
git clone https://github.com/pollybich/pollyDrop.git /opt/pollydrop
cd /opt/pollydrop
./deploy/server/install-debian.sh
```

Если каталог существует, сначала проверьте его содержимое. Установщик добавляет недостающий Compose из официального выпуска Docker с проверкой SHA-256. Backend и интерфейс берутся из опубликованного `v0.1.0-beta.4`, проверяются по SHA256SUMS и упаковываются в контейнеры. Компиляторы Java и Node.js на хосте не нужны.

`.env` создаётся локально один раз; ключ шифрования и пароль БД не меняются при обновлении. Готовые сборки находятся в игнорируемом `.runtime/server`. PostgreSQL и backend не публикуются; frontend слушает `127.0.0.1:8088`. Caddy получает и продлевает сертификат для `drop.pollybich.ru`. Используются HTTP/1.1 и HTTP/2, без объявления недоступного HTTP/3.

## Подключение существующей установки

Для перехода из прежнего checkout используйте новую папку, сохранив `.env`. Это сохраняет ключи и не затрагивает исходный checkout. Выполняйте из текущей папки проекта; `/opt/pollydrop` должна быть свободна:

```bash
POLLY_SOURCE_DIR="$PWD"
git clone https://github.com/pollybich/pollyDrop.git /opt/pollydrop &&
install -m 600 "$POLLY_SOURCE_DIR/.env" /opt/pollydrop/.env &&
cd /opt/pollydrop &&
./deploy/server/update-debian.sh
```

Если `/opt/pollydrop` уже существует, не перезаписывайте её: сначала проверьте, какая установка в ней находится. Перед переносом настройте DNS `drop.pollybich.ru` на сервер. Следующие обновления выполняются обычной командой ниже.

## Обновление

Из текущей папки проекта:

```bash
git pull --ff-only
./deploy/server/update-debian.sh
```

Сначала скачиваются и проверяются готовые сборки, затем собираются образы. Если на 8088 найдена предыдущая установка этого сервиса, скрипт сверяет её ключи с `.env`, останавливает её и делает холодную копию БД, зашифрованных файлов и сертификатов в volumes `pollydrop-public`. В копии БД и роль переименовываются в `pollydrop`; ключ шифрования, пароль, UUID, сроки и счётчики сохраняются. Исходные volumes остаются для восстановления. Если копирование или переименование не удалось, исходные контейнеры запускаются снова.

После переноса запускается новый проект, перечитывается Caddy и проверяются версия backend и фактический JavaScript, отдаваемый frontend. Одна работающая `/api/health` не считается доказательством обновления интерфейса. По умолчанию выбран **1 час**, максимум — **2 дня**.

Перенос включает краткую остановку сервиса. Старые отправленные ссылки содержат прежний домен: используйте тот же путь `/s/...` на новом адресе, пока срок и лимит действуют. Автоматический редирект прежнего домена не создаётся. Сохранённые исходные volumes — резервные копии; их срок хранения устанавливает администратор.

Для явной сборки frontend из checkout доступен `--frontend-from-source`; обычное обновление использует готовую сборку релиза.

## Проверка и журналы

```bash
curl --fail https://drop.pollybich.ru/api/health
docker compose -p pollydrop-public -f compose.yaml -f deploy/server/compose.server.yaml logs --tail=50 backend caddy
```

Ожидаются `status: ok`, версия `0.1.0-beta.4`. Проверьте новую форму, переключатель RU / EN и тестовую передачу. Если обновить нужно только интерфейс уже перенесённой установки:

```bash
./deploy/server/update-interface.sh
```

Скрипт скачивает текущий frontend, заменяет только его контейнер и сравнивает отдаваемый JavaScript с собранным образом.

## Данные и ограничения

Проект `pollydrop-public` использует отдельные volumes БД, файлов и сертификатов. `docker compose ... down` сохраняет их; не добавляйте `-v`. Для восстановления нужны БД, содержимое и исходный `APP_MASTER_KEY`. Восстановление устаревшей копии требует отозвать ранее созданные передачи, чтобы не повторить уже использованную выдачу. Автоматические бэкапы не настраиваются.

Nginx ограничивает создание 12 передачами в минуту с небольшим burst и задаёт общий предел двух одновременных созданий/выдач. При перегрузке — 429. Секретные пути исключены из HTTP-журналов. Это начальные ограничения беты, не полноценная защита от злоупотреблений.

## Язык по стране

Backend использует встроенную локальную базу стран DB-IP Lite: `RU` выбирает русский, остальные страны и неизвестные адреса — английский. IPv4 и IPv6 поддерживаются. Caddy очищает недоверенные forwarding-заголовки, Nginx передаёт адрес клиента приватному backend. Адрес не отправляется внешнему GeoIP API и не записывается этим механизмом в БД или журнал. Ручной выбор хранится в браузере и имеет приоритет. VPN и прокси могут изменить определяемую страну.
