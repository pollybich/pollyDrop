# Roadmap

План pollyDrop без календарных дат. Отметка означает реализованное и проверенное поведение. Полный реестр функций — [REQUIREMENTS](docs/REQUIREMENTS.md); в первую бету включён гостевой обмен.

## Первая бета — v0.1.0-beta.1

- [x] React + TypeScript, Java 21 + Spring Boot, PostgreSQL, миграции Flyway.
- [x] Светлый адаптивный интерфейс: матовое стекло, крупная типографика, анимации и reduced motion.
- [x] Файл до 25 МиБ и текст до 64 КиБ без регистрации.
- [x] Срок, лимит получений и пароль.
- [x] Непредсказуемые ссылки, отдельный токен управления и отзыв.
- [x] AES-256-GCM для содержимого, Argon2id для паролей, хеши токенов в базе.
- [x] Только явное получение; открытие страницы не расходует лимит.
- [x] Атомарный резерв, защита от конкурентных запросов и повтор после обнаруженного обрыва.
- [x] Очистка недоступного содержимого и восстановление резервов после перезапуска.
- [x] Интеграционные и браузерные проверки, инструкции запуска и API.
- [x] Проверить полную сборку и запуск Docker.
- [x] Опубликовать предварительный выпуск с исходниками и сборками.

## Первое обновление — v0.1.0-beta.2

- [x] Нативная загрузка файлов через менеджер браузера, без Blob URL.
- [x] Повтор чтения метаданных при временных сетевых ошибках и кнопка повтора.
- [x] Ошибка обновления состояния сохраняет уже полученное содержимое.
- [x] Удаление после последнего получения или отзыва; таймер срока и восстановление после перезапуска.
- [x] Максимум хранения 2 дня, включая миграцию старых передач.
- [x] Удалить стрелку из логотипа.
- [x] Отключить объявление HTTP/3 без доступного UDP-порта.
- [x] Подготовить обновление Debian с сохранением данных и ключей.

## Доработка беты

- [ ] Собрать отзывы об интерфейсе и сценариях обмена.
- [ ] Проверить Safari и Firefox на реальных устройствах.
- [ ] Добавить защиту от массовых загрузок и ограничения общего числа одновременных запросов.
- [ ] Сделать ограничение паролей устойчивым к перезапуску и настроить доверенные proxy.
- [ ] Провести нагрузочные испытания и проверку безопасности.
- [ ] Подготовить внешнее размещение с доменом, HTTPS, наблюдаемостью и резервными копиями.
- [ ] Определить политику хранения и удаления метаданных.

## Аккаунты и управление

- [ ] Регистрация, вход, сессии и выход.
- [ ] Кабинет со списком передач, состояниями и статистикой.
- [ ] Связь передач с владельцем аккаунта; проверки владения.
- [ ] Сохранить создание и получение без аккаунта.

## Публичное и внутреннее использование

- [ ] Настроить внутреннюю установку и руководство администратора.
- [ ] Описать обновления, восстановление и ротацию ключей.
- [ ] Добавить публичный режим и рекламные блоки с учётом приватности.
- [ ] Исключить сторонние рекламные скрипты со страниц передачи и кабинета.
- [ ] Отключать рекламу при внутреннем размещении.

## Дальнейшее развитие

- [ ] Оценить S3-совместимое хранилище и поддержку нескольких backend.
- [ ] Развивать корпоративное управление по конкретным запросам.
- [ ] Рассмотреть сквозное шифрование отдельным архитектурным изменением.

Новые функции добавляются после оценки безопасности и нагрузки одного разработчика. Постоянное хранение и нативные приложения не входят в текущий объём.

## v0.1.0-beta.4

- [x] Загрузка зашифрованными частями с сохранением прогресса в БД.
- [x] Продолжение после перезагрузки страницы и backend, с проверкой исходного файла SHA-256.
